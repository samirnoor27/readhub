# مدوّنة أفق — قالب عربي ثابت

قالب RTL عربي متعدد الصفحات، يعمل مباشرة من ملفات HTML/CSS/JavaScript دون Node.js أو خطوة بناء.

## الملفات
- `index.html`: الصفحة الرئيسية، البحث، التصنيفات، والصفحات المتتابعة.
- `article-1.html` إلى `article-5.html`: خمسة مقالات تجريبية مستقلة.
- `category.html` و`tag.html`: صفحات تصنيف ووسم أولية.
- `links.html`: مكتبة روابط رسمية للبرامج والألعاب.
- `about.html`: صفحة التعريف.
- `styles.css` و`scripts.js`: التصميم والتفاعلات.
- `rss.xml` و`sitemap.xml` و`robots.txt`: ملفات مساعدة لمحركات البحث والخلاصات.
- `netlify.toml`: ترويسات تخزين مؤقت اختيارية.

## تشغيل محلي
افتح `index.html` في المتصفح. يمكن أيضًا تشغيل خادم محلي بسيط من مجلد المشروع:
```bash
python -m http.server 8000
```
ثم افتح `http://localhost:8000`.

## قبل النشر (مهم)
1. استبدل كل `https://example.com` بعنوان موقعك الحقيقي في canonical وOpen Graph وRSS وsitemap وrobots.
2. حدّث تواريخ المقالات والمحتوى التجريبي وبيانات JSON-LD حسب المحتوى الفعلي.
3. أنشئ صورة مشاركة اجتماعية حقيقية في `assets/og-cover.svg` أو عدّل رابط `og:image` إلى صورة عامة متاحة على HTTPS.
4. راجع روابط الموارد الخارجية وسياسة الخصوصية/التواصل إن أضفت نماذج أو تحليلات.
5. ارفع الملفات إلى جذر النشر، لا ترفع ملف ZIP نفسه فقط.

## نشر GitHub Pages
1. أنشئ مستودعًا جديدًا على GitHub وارفع محتويات هذا المجلد إلى الجذر.
2. من المستودع افتح **Settings → Pages**.
3. في **Build and deployment** اختر **Deploy from a branch**.
4. اختر الفرع `main` والمجلد `/(root)` ثم **Save**.
5. انتظر اكتمال النشر وافتح الرابط الذي يعرضه GitHub Pages.
6. بعد كل تعديل، نفّذ `git add .`, ثم `git commit -m "Update blog"` ثم `git push`؛ يعيد GitHub Pages النشر تلقائيًا.

## نشر Netlify بنقرة/سحب وإفلات
**أبسط طريقة:** سجّل الدخول إلى Netlify، افتح صفحة إضافة موقع يدويًا (Deploy manually)، ثم اسحب مجلد الموقع بعد فك الضغط إلى منطقة النشر. قد تتغير أسماء عناصر الواجهة بمرور الوقت.
**نشر مستمر:** اربط مستودع GitHub بالموقع في Netlify. اجعل Publish directory هو `.` واترك Build command فارغًا. بعد ذلك، كل `git push` ينشر التحديث تلقائيًا.

## كيف تحدّث المقالات؟
- عدّل نصوص المقالات في ملفات `article-N.html`.
- أضف بطاقة جديدة في `index.html` مع رابط المقال و`data-category` و`data-tags`.
- أضف عنصرًا مطابقًا في `rss.xml` وأضف الرابط إلى `sitemap.xml`.
- حدّث أعداد التصنيفات والوسوم في الصفحة الرئيسية عند الحاجة.
- هذا قالب HTML ثابت: البحث والتصفية والترقيم يعملان على البطاقات الموجودة في `index.html` فقط. صفحات التصنيف والوسم الحالية قوالب خفيفة وليست نظام إدارة محتوى ديناميكيًا.

## ملاحظات الأداء والوصولية
- الصور غير موجودة في بطاقات النموذج؛ الرسومات مصنوعة بـ CSS، لذلك لا توجد طلبات صور أو حاجة إلى lazy loading لها. عند إضافة صور فعلية استخدم `loading="lazy"` و`decoding="async"` و`width` و`height`، واترك صورة الجزء العلوي المهمة دون lazy loading.
- خط Cairo يجلب من Google Fonts؛ عند تعذر الاتصال تُستخدم خطوط النظام كبديل.
- التصميم يدعم RTL، التنقل بلوحة المفاتيح، رابط تجاوز المحتوى، حالات تركيز واضحة، وتقليل الحركة حسب إعداد النظام.
- القالب جاهز كنقطة انطلاق للنشر، لكنه لا يُعد تدقيقًا قانونيًا/أمنيًا أو ضمانًا نهائيًا لمعايير WCAG. اختبر التباين والمحتوى والروابط في بيئة الإنتاج.
